01 — About Me
HAU · CS '27

Hi, I'm Ashley!

I'm a 4th-year Computer Science student at Holy Angel University in Angeles City, Pampanga, with a GWA of 1.21 and an expected graduation in April 2027. My coursework and research center on intelligent systems and data analytics.

This year I built a real-time volleyball referee whistle detector in Python that reaches 98% accuracy on unseen data, then packaged it with Docker for user testing.

I'm also an illustrator and designer, and I bring the same care, intention, and a little bit of whimsy to every interface, poster, and sticker I make!

Volleyball Whistle Detector

Featured

Real-time referee whistle detector combining SVM, Random Forest and Gradient Boosting, trained on 1,930 audio clips. Reaches 98% accuracy on unseen data, validated with grouped cross-validation on venues it had never heard, and packaged with Docker for user testing.

Swiss Artsy Knife — Digital Creative Toolbox

Live demo ↗

A free multi-purpose web app for digital creatives with four tools: a color palette generator, background remover, QR generator and zine layout. Built on the PERN stack, with a Node.js/Express REST API (JWT, bcrypt, rate limiting) on a Supabase-hosted PostgreSQL database, deployed with Render and GitHub Actions.

JeepMiyabe — Jeepney Route Finder

A cross-platform mobile app that helps commuters navigate 11 official jeepney routes in Angeles City. It recommends routes with Dijkstra's algorithm based on distance, travel time and transfer costs, shows routes and the user's location with Google Maps and GPS, and uses Supabase authentication so users can save favorite destinations.

  • Flutter
  • Dart
  • Supabase
  • Google Maps
  • Dijkstra's
